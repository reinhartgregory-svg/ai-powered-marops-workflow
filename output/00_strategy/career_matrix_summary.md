## 6. Main Work-Environment Risks (screen out)
- Growth-stage / "build-the-entire-MarTech-function-solo" roles (**highest-risk pattern**)
- Agency positions with heavy client escalation, daily reprioritization, account-service duties
- "AI expert" titles that actually require production ML/engineering or autonomous-system builds
- RevOps/CRM roles requiring advanced CPQ, quote-to-cash, Salesforce architecture
- Data governance requiring deep MDM architecture / formal DG frameworks / data engineering
- Analytics roles requiring advanced production SQL, statistics, data science, experimentation ownership
- Salesforce Admin roles treating Flow/Apex/Agentforce as day-one requirements
- Commission-heavy / disguised-sales roles; high-volume ticket/queue throughput; always-on availability
- "Remote" roles requiring frequent unplanned office attendance

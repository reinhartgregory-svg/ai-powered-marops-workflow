# Search Configuration
**Compiled:** 2026-07-10 · **Application Mode: REVIEW_ONLY**

---

## Geography
- Remote roles based in the **United States**.
- Must **verify remote roles accept applicants residing in Ohio** (Akron).
- "Remote" is **not** assumed nationwide — confirm state eligibility per posting.
- Flag: location restrictions, required time zones, travel expectations, hybrid/in-office days.

## Employment Types
- Full-time; **direct-hire preferred**.
- Contract roles included only when strategically valuable — **clearly labeled**.

## Recency
- **0–7 days** first.
- Expand to **14 days** if fewer than 15 strong matches.
- Expand to **30 days** only for unusually strong / hard-to-find roles.

## Seniority Band
Specialist · Analyst · Senior Specialist · Senior Analyst · Coordinator (only if career-building) ·
Manager (only if individual-contributor / hands-on ops). **Avoid** Director/Executive unless
requirements clearly match documented experience.

## Sources
**Primary:** LinkedIn Jobs · Indeed · Direct employer career pages
**Secondary:** Built In · Glassdoor · ZipRecruiter · Wellfound · Dice · Google Jobs · Welcome to the Jungle · reputable industry boards · reputable staffing sites (labeled contract).

**Available in this environment (tooling):** Indeed MCP · ZipRecruiter MCP · Dice MCP · WebSearch / WebFetch for LinkedIn/employer/Google Jobs/Built In/Glassdoor/Wellfound.

## Compliance Guardrails
No CAPTCHA circumvention · no login bypass · no rate-limit evasion · no identity rotation · no
unauthorized accounts · no deceptive browser behavior · scrape only where terms/controls permit.
When automation is blocked → record and continue via permitted methods.

## Batch Size (proposed)
- **Search batch:** review ~40–60 raw postings per session across role families.
- **Shortlist batch:** present top **12–15** verified, de-duplicated roles for approval.
- **Prep batch:** tailor resumes only for **approved** Job IDs (or top-5 Priority Apply if you pre-authorize a prep batch).

## Fit-Score Threshold
Do not recommend applying below **65** unless an explicit, compelling strategic reason is documented.

## Application Mode — REVIEW_ONLY (active)
Open pages · populate supported fields · upload approved tailored resume · draft answers ·
**STOP at final review/submit screen**. Never click Submit/Send/Apply/final action.
Switch to SUBMIT_APPROVED only on an explicit list of approved application IDs.
